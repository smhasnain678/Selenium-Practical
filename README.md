# Selenium Practical

This repository contains my practical exercises and automation tasks using **Python and Selenium WebDriver**.

## Technologies Used

- Python
- Selenium WebDriver
- Pytest
- Chrome WebDriver
- Firefox WebDriver
- Allure Reports
- Git & GitHub

## Topics Covered

- Selenium WebDriver basics
- Locating elements using:
  - ID
  - Name
  - Class Name
  - Tag Name
  - Link Text
  - Partial Link Text
  - XPath
  - CSS Selector
- Browser navigation and window handling
- Multiple browser windows/tabs
- `driver.close()` and `driver.quit()`
- Implicit waits and explicit waits
- Handling tables and extracting rows/columns
- Parameterization with Pytest
- Pytest markers
- Parallel test execution
- Allure Reports
- CSV data handling
- Email automation
- Web automation practical tasks
